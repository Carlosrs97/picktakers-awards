# Picktakers Awards

Web de votaciones de los premios en tres fases: temáticas, nominados y votación final, más la gala.

- Web: https://carlosrs97.github.io/picktakers-awards/
- Datos: Firebase (proyecto `picktakers-awards`), con inicio de sesión de Google.
- `firestore.rules`: copia de las reglas publicadas en Firestore.

## Vídeos y fotos
Los archivos de las nominaciones de mensajes, vídeos o fotos van en la carpeta `media/`. En la web, en cada nominado, se escribe el nombre exacto del archivo o un enlace (YouTube u otro).
